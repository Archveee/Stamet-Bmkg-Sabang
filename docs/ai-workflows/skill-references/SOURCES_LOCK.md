## Catatan URL
URL yang sebelumnya diberikan sebagai `https://github.com/WenyuChiou/academic-writing-skillsa` tidak dapat diakses sebagai repositori publik melalui `git ls-remote` (Git menolak akses anonim). URL tanpa huruf `a` terakhir dapat diakses dan itulah sumber clone yang disimpan di folder lokal `academic-writing-skillsa`.

## Pemeliharaan
Untuk memperbarui referensi, lakukan di folder referensi masing-masing dan periksa perubahan terlebih dahulu. Jangan menggabungkan repositori skill ini ke riwayat Git aplikasi sebagai submodule/nested repository. Folder-folder clone dikecualikan secara lokal melalui `.git/info/exclude`; dokumen workflow di luar folder clone tetap tampak sebagai berkas untracked sampai Anda memilih untuk memasukkannya ke Git.
