# Referensi Skill Publik

Folder ini menyimpan salinan lokal repositori skill publik sebagai referensi prosedur. Menyimpan repositori di sini tidak mengaktifkan skill secara otomatis.

## Repositori sumber yang diperiksa
- proposal-skripsi-skill: https://github.com/bimajanuri/proposal-skripsi-skill
- academic-writing-skills: https://github.com/WenyuChiou/academic-writing-skills
  - Catatan: URL dengan akhiran `academic-writing-skillsa` yang pertama diberikan tidak ditemukan sebagai repositori publik; salinan ini menggunakan URL tanpa huruf `a` terakhir.
  - Direktori lokal tetap bernama `academic-writing-skillsa` agar mudah dikenali terhadap daftar awal.
- RhetoriLex: https://github.com/rezaprama/RhetoriLex
- paper-review-skill: https://github.com/bimajanuri/paper-review-skill

## Cara menggunakan
1. Baca `SKILL.md` dan file referensi yang relevan sebelum mengadaptasi instruksinya.
2. Gunakan skill sebagai prosedur kerja manual bersama ChatGPT dan Desktop Commander.
3. Jangan jalankan skrip dari repositori sebelum memeriksa isi, dependensi, dan dampaknya.
4. Jangan gunakan template kampus bawaan sebagai pengganti template resmi D3 Manajemen Informatika USK.
5. Jangan menyalin kalimat, data pribadi, atau substansi proposal contoh.
6. Pertahankan lisensi/atribusi tiap repositori.

## Batasan
Desktop Commander menyediakan akses lokal ke berkas dan terminal. Ia tidak otomatis memuat atau mengaktifkan Agent Skills dalam cara kerja Gemini CLI/Claude Code. Workflow ada pada `../workflows/` untuk dipakai dengan meminta Desktop Commander membaca file yang diperlukan.
