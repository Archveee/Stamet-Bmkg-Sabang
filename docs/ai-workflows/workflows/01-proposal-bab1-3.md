# Workflow 01 — Proposal Seminar BAB I–III

## Prasyarat
- Struktur dan format sudah dicocokkan dengan template resmi D3 MI.
- Ada ringkasan proyek dan inventaris fitur dari hasil audit kode.
- Klaim masalah memiliki bukti atau ditandai belum terverifikasi.
- Artikel literatur memiliki sumber yang dapat diperiksa.

## Tahapan
1. Kunci ruang lingkup dan istilah yang digunakan.
2. Buat peta klaim-bukti untuk BAB I.
3. Susun matriks penelitian terdahulu dan teori untuk BAB II.
4. Cocokkan metode, jadwal, alat/bahan, rancangan, dan pengujian untuk BAB III.
5. Jalankan audit konsistensi lintas bab.
6. Minta pembimbing memvalidasi draf sebelum finalisasi.

## Prompt
Bantu menyusun proposal proyek akhir berjudul "Pengembangan Sistem Informasi Pengelolaan serta Pengiriman Sandi Cuaca GTS dan Meteorologi Berbasis Web pada Stasiun Meteorologi BMKG Sabang".

Target saat ini BAB I–III. Aplikasi Laravel/PHP sudah dikembangkan dan pengiriman memakai mekanisme yang telah digunakan BMKG. Jangan menyimpulkan detail integrasi sebelum dibuktikan oleh source code dan dokumen operasional yang diizinkan.

Gunakan template resmi D3 MI sebagai acuan format. Untuk setiap subbab, berikan: tujuan bagian, klaim/argumen, bukti sumber, draf, informasi yang belum tersedia, dan pertanyaan untuk pembimbing. Jangan mengarang observasi, wawancara, statistik, sitasi, fitur, atau hasil uji.

Kembangkan BAB I, BAB II, dan BAB III secara terpisah. Jangan tulis seluruh proposal final dalam satu jawaban sebelum kerangka dan sumber diverifikasi.
